# Mactician 1.3.4 — TFT 18.7 graphics and interface scale

- Restore native rendering resolution after TFT 18.7 reduced it, making the game look blurry.
- Preserve the configured frame-rate limit when TFT applies its device profiles.
- Add **75% interface scale** for a smaller game UI. Select it in Mactician settings and restart the game.

## Known issue

Spirit Blossom Yunara’s name and HP bar can appear far above the tactician. This release does not fix that tactician-specific placement issue. Switching to Shork was verified as a workaround on the tested installation.
