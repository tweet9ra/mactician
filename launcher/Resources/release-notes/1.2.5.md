# Mactician Release Notes — 1.2.5

- Use game-log signals instead of screenshot recognition to identify the context
  of performance measurements across game languages and display resolutions.
- Distinguish recent lobby, matchmaking, match-starting and match activity.
  Missing, stale or inconsistent signals remain unknown; these observations do
  not claim to identify the current combat phase or numbered round.
- Remove screenshot/OCR work from performance collection. Game packages,
  graphics settings and the collection duty budget are unchanged.
- Raw game logs, account details and screenshots are never saved or uploaded.

Build 54 for Apple Silicon, macOS 12 or later.
